## 🇬🇧 English

### Overview

A full-stack restaurant management web application for real-time ordering and menu management, built with the MERN-style stack (MongoDB, Express, React, Node.js).

### Tech Stack

| Layer | Technologies |
|---|---|
| Backend | Node.js, Express 5, MongoDB (Mongoose), JWT, bcryptjs, Multer, Nodemailer |
| Frontend | React 19, Vite, React Router, Tailwind CSS, Axios, react-hot-toast |

### Key Features

- Menu and order management with a MongoDB-backed data layer.
- Authentication with JWT and hashed passwords (bcryptjs).
- Image uploads (e.g. menu item photos) via Multer.
- Email notifications via Nodemailer.
- Responsive, toast-driven UI built with React, React Router, and Tailwind CSS.

### Project Structure

```
backend/    Node.js + Express + MongoDB REST API
frontend/   React + Vite client application
```

### Getting Started

#### Backend

```bash
cd backend
npm install
npm run server   # starts with nodemon
# or: npm start
```

#### Frontend

```bash
cd frontend
npm install
npm run dev
```
